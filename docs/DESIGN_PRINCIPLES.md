# Design Principles

## 1. 产品气质

AI Talent Agent 的 UI 应体现：

- 专业。
- 可信。
- 清晰。
- 克制。
- 面向职业决策。

它不是娱乐化 AI 工具，也不是传统厚重 HR 系统。视觉上应介于“现代职业服务产品”和“B2B 工作台”之间。

## 2. 设计关键词

推荐关键词：

- clean。
- professional。
- trustworthy。
- calm。
- structured。
- data-informed。
- human-centered。

不推荐关键词：

- flashy。
- playful。
- cyberpunk。
- overly futuristic。
- gamified。
- childish。

## 3. 信息层级

页面应遵守：

1. 先展示结论。
2. 再展示原因。
3. 最后展示证据。

例如人才画像页：

```text
总体摘要
  -> 能力评分
  -> 优势和风险
  -> 证据链
```

例如 HR 匹配页：

```text
推荐分数
  -> 推荐理由
  -> 风险点
  -> 面试问题
  -> 证据
```

## 4. 候选人侧视觉方向

候选人侧应更引导式：

- 强步骤感。
- 卡片式信息。
- 温和提示。
- 强调用户可校对、可修改、可继续补充。

避免：

- 上来展示复杂数据仪表盘。
- 使用过度评判性的文案。
- 让用户觉得 AI 在“审判”自己。

## 5. HR 侧视觉方向

HR 侧应更工作台化：

- 列表。
- 筛选。
- 分数。
- 导出。
- 复制。
- 风险和面试问题。

避免：

- 只展示抽象画像，不给可执行材料。
- 隐藏证据。
- 让 HR 必须学习一套全新流程。

## 6. 色彩建议

主色：

- 深蓝。
- 靛蓝。
- 蓝紫。

辅助色：

- 青绿：成功、高置信度。
- 琥珀：风险、低置信度、待验证。
- 灰蓝：信息提示。

背景：

- 近白。
- 浅灰。
- 微弱蓝灰渐变。

避免：

- 大面积红色。
- 高饱和霓虹色。
- 过多彩色标签。

## 7. 组件风格

推荐：

- 圆角卡片。
- 轻阴影。
- 清晰边界。
- 适度留白。
- 表格和卡片结合。
- 证据链可折叠。

不推荐：

- 过度玻璃拟态。
- 高复杂 3D 装饰。
- 信息密度过高。
- 每个模块都使用强视觉效果。

## 8. 可解释性设计

凡是 AI 生成结论，都应尽量配套：

- 证据入口。
- 置信度标签。
- “需要验证”提示。
- 重新生成或继续补充入口。

结论不应孤立展示。

## 9. 状态设计

必须考虑：

- 空状态。
- 加载状态。
- 错误状态。
- 低置信度状态。
- 信息不足状态。
- 解析失败状态。
- 导出失败状态。

每个状态都要告诉用户下一步可以做什么。

## 10. 响应式原则

第一版优先桌面端。

原因：

- HR 工作流多在桌面完成。
- 简历预览、画像详情、候选人列表需要较大屏幕。
- 后续可适配移动端候选人访谈。

桌面优先布局：

- 宽屏双栏。
- 左侧流程 / 导航。
- 右侧详情 / 证据。
- 列表 + 详情模式。

# Product Brief

## 1. 一句话定位

AI Talent Agent 是一个以人才画像为核心的 AI 招聘基础设施：通过简历解析和 AI 深度访谈理解候选人，再基于人才画像生成简历、匹配岗位、推荐候选人。

## 2. 产品使命

让 AI 比 HR 更了解候选人。

这里的“更了解”不是替代 HR 做最终判断，而是在招聘早期完成更系统、更一致、更可追溯的候选人理解。

## 3. 产品愿景

构建可持续积累的人才画像数据库，让候选人的真实能力、职业倾向和岗位需求之间形成高质量连接。

## 4. 核心洞察

传统招聘存在三个结构性问题：

1. 简历表达能力有限。
   - 简历通常只呈现经历标题和职责描述，很难表达真实贡献、思考过程和能力质量。

2. HR 早期筛选依赖关键词。
   - 关键词可以筛掉一部分明显不匹配的人，但无法判断学习能力、执行能力、职业倾向和潜力。

3. 简历优化和岗位匹配缺少统一中间层。
   - 如果没有稳定的人才画像，简历生成只是文案润色，岗位匹配只是关键词匹配。

AI Talent Agent 的核心中间层是人才画像。

但产品落地时不能只依赖新范式。HR 已经有固定工具和流程，因此 AI Talent Agent 应首先兼容传统招聘工作流，把 AI 人才画像转化为 HR 熟悉的简历、摘要、表格、面试问题和候选人报告。

## 5. 目标用户

### 5.1 第一优先用户：求职者

第一阶段建议优先服务求职者。

原因：

- 求职者侧更容易形成单用户闭环。
- 不依赖企业端供给即可验证产品价值。
- 人才画像质量需要先通过候选人侧打磨。
- HR 匹配依赖稳定的人才画像，适合作为第二阶段。

典型用户：

- 不知道如何表达项目亮点的应届生。
- 需要转岗或转行的 1-5 年经验候选人。
- 希望针对不同岗位生成简历版本的人。
- 想知道自己适合什么岗位和能力短板的人。

核心需求：

- 看清自己的能力结构。
- 补全简历中没有表达出来的信息。
- 生成更符合岗位和平台的简历版本。
- 获得岗位方向建议。

### 5.2 第二阶段用户：HR / 招聘方

HR 侧建议在候选人画像质量稳定后接入。

典型用户：

- 创业公司创始人或业务负责人。
- 中小企业 HR。
- 猎头顾问。
- 需要快速筛选候选人的招聘团队。

核心需求：

- 用自然语言描述岗位需求。
- 快速获得候选人推荐。
- 理解推荐原因和风险点。
- 获得面试追问建议。

## 6. 核心价值主张

对求职者：

- AI 不只是改简历，而是先理解候选人。
- 简历生成基于真实画像，而不是泛化模板。
- 用户可以看到自己的能力结构、优势和风险点。

对 HR：

- 候选人推荐不只是关键词匹配。
- 每个推荐都有理由、风险和面试建议。
- 岗位需求可以用自然语言输入，由 AI 拆解成岗位画像。
- 输出结果可以进入现有 ATS、Excel、邮件、飞书、企业微信等工作流。

## 7. 第一阶段产品形态

第一阶段产品建议是候选人侧 Web App：

```text
上传简历 -> AI 解析 -> AI 访谈 -> 人才画像 -> 简历生成
```

核心页面：

- 简历上传页。
- 简历解析结果页。
- AI 访谈页。
- 人才画像页。
- 简历生成页。

## 8. 第二阶段产品形态

第二阶段加入 HR 侧匹配：

```text
HR 输入岗位需求 -> AI 拆解岗位画像 -> 匹配人才画像 -> 推荐候选人
```

核心页面：

- 岗位需求输入页。
- 推荐候选人列表页。
- 候选人匹配详情页。

HR 侧第一版不应强迫用户迁移系统，而应优先提供：

- 候选人一页摘要。
- 标准简历导出。
- Excel / CSV 候选人表。
- 可复制的推荐理由。
- 可复制的面试问题。
- 飞书 / 企业微信 / 邮件可转发摘要。

## 9. MVP 核心假设

MVP 需要验证以下假设：

1. AI 能否从简历中稳定提取结构化信息。
2. AI 访谈能否问出简历里没有表达的信息。
3. 人才画像能否让候选人觉得“它理解我”。
4. 人才画像能否支撑更好的简历生成。
5. 人才画像能否支撑可解释的人岗匹配。

## 10. 第一版不做什么

MVP 阶段明确不做：

- 企业 ATS 深度 API 集成。
- 候选人自动投递。
- HR 复杂权限和团队协作。
- 招聘流程管理。
- 付费系统。
- 大规模人才库运营。
- 背调和经历真实性验证。
- 复杂多 Agent 自主规划框架。

## 11. 成功标准

第一阶段成功标准：

- 候选人可以从一份简历生成可信的人才画像。
- 候选人认为画像中的优势、风险和职业方向基本准确。
- 系统能基于画像生成至少两种可用简历版本。
- 每个画像结论都能追溯到简历或访谈证据。

第二阶段成功标准：

- HR 可以用自然语言创建岗位需求。
- 系统能给出候选人匹配排序。
- 推荐结果包含分数、理由、风险和面试问题。
- HR 能理解为什么推荐某个候选人。
- HR 能把候选人摘要、推荐理由或面试问题复制/导出到现有工作流中。

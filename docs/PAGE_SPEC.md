# Page Spec

## 1. 目标

本文件定义 AI Talent Agent MVP 的页面规格，用于指导 UI 原型生成。

每个页面都应体现三个设计原则：

- 清晰：用户知道当前处于哪一步。
- 可信：AI 结论有证据、有置信度、有可编辑入口。
- 兼容：输出能进入传统 HR 工作流。

## 2. 页面清单

MVP UI 建议包含：

- 首页。
- 简历上传页。
- 简历解析校对页。
- AI 访谈页。
- 人才画像页。
- 简历生成页。
- HR 岗位需求输入页。
- 岗位画像确认页。
- 候选人推荐列表页。
- 候选人匹配详情页。
- HR 导出包页。
- 内部调试页。

## 3. 首页

页面目标：

- 解释产品价值。
- 分流候选人和 HR。

核心信息：

- 标题：让 AI 先理解候选人，再生成简历和岗位匹配。
- 副标题：通过简历解析、AI 访谈和人才画像，输出可解释的简历、推荐理由和面试问题。

主要模块：

- Hero 区。
- 候选人侧流程卡片。
- HR 侧流程卡片。
- 产品可信机制：证据链、置信度、不编造。
- CTA。

主要按钮：

- 开始生成我的人才画像。
- 查看 HR 侧演示。

状态：

- 首次访问。
- 已有画像时提示继续上次流程。

## 4. 简历上传页

页面目标：

- 上传简历文件。
- 提醒用户复杂模板可能影响解析。

主要模块：

- 文件上传卡片。
- 支持格式说明：PDF、Word。
- 解析质量提示。
- 隐私说明。

主要按钮：

- 选择文件。
- 开始解析。
- 查看示例简历。

空状态：

- 未选择文件。

错误状态：

- 格式不支持。
- 文件过大。
- 文本无法提取。

提示文案重点：

- 建议上传结构清晰、ATS 友好的简历。
- 复杂视觉模板可作为输出模板，但不建议作为画像生成的主要输入。

## 5. 简历解析校对页

页面目标：

- 展示结构化简历。
- 允许用户修正解析错误。

主要模块：

- 顶部步骤条。
- 解析质量评分。
- 基础信息编辑区。
- 教育经历编辑区。
- 工作经历编辑区。
- 项目经历编辑区。
- 技能标签编辑区。
- 缺失字段提示。

主要按钮：

- 保存修改。
- 添加经历。
- 确认并开始 AI 访谈。
- 重新上传。

状态：

- 字段完整。
- 字段缺失。
- 解析置信度低。

## 6. AI 访谈页

页面目标：

- 通过多轮问答补全画像证据。

主要模块：

- 访谈阶段指示器。
- 聊天区域。
- 当前问题卡片。
- 问题原因。
- 目标能力标签。
- 输入框。
- 访谈进度。
- 画像证据缺口提示。

主要按钮：

- 发送。
- 跳过此问题。
- 结束并生成画像。

状态：

- 等待用户回答。
- AI 生成下一问。
- 信息不足提示。
- 可生成画像提示。

## 7. 人才画像页

页面目标：

- 展示候选人的能力结构、优势、风险和职业方向。

主要模块：

- 人才画像摘要。
- 能力评分雷达或卡片。
- 8 个能力维度详情。
- 核心优势。
- 潜在风险。
- 职业偏好。
- 推荐岗位方向。
- 证据链抽屉。
- 置信度说明。

主要按钮：

- 查看证据。
- 生成简历版本。
- 继续补充访谈。
- 导出画像摘要。

状态：

- 高置信度画像。
- 中置信度画像。
- 低置信度画像。

## 8. 简历生成页

页面目标：

- 基于画像生成不同用途的简历内容。

主要模块：

- 简历版本 Tab：ATS 版、HR 版、平台简介、邮件正文。
- 简历预览。
- 内容来源提示。
- 不编造提醒。
- 导出按钮组。

主要按钮：

- 重新生成。
- 复制文本。
- 导出 Word。
- 导出 PDF。
- 返回画像。

状态：

- 生成中。
- 生成成功。
- 内容过长提示。
- 缺少证据提示。

## 9. HR 岗位需求输入页

页面目标：

- 让 HR 用自然语言输入岗位需求。

主要模块：

- 岗位需求输入框。
- 示例岗位需求。
- 关键信息提示。
- 传统流程兼容说明。

主要按钮：

- 生成岗位画像。
- 使用示例数据。

状态：

- 输入为空。
- 输入过短。
- 生成中。

## 10. 岗位画像确认页

页面目标：

- 让 HR 校对岗位画像。

主要模块：

- 岗位基础信息。
- 核心职责。
- 必备技能。
- 加分技能。
- 能力要求。
- 职业倾向要求。
- 缺失字段提示。

主要按钮：

- 编辑。
- 开始匹配候选人。
- 返回修改岗位需求。

状态：

- 信息完整。
- 信息不足。

## 11. 候选人推荐列表页

页面目标：

- 展示按匹配度排序的候选人。

主要模块：

- 岗位摘要。
- 推荐候选人列表。
- 候选人卡片。
- 总匹配分。
- 分项得分。
- 推荐理由摘要。
- 风险标签。
- 筛选和排序。

主要按钮：

- 查看详情。
- 复制摘要。
- 加入导出包。
- 导出列表。

状态：

- 无候选人。
- 匹配中。
- 推荐结果为空。

## 12. 候选人匹配详情页

页面目标：

- 解释候选人与岗位的匹配关系。

主要模块：

- 候选人一页摘要。
- 总匹配分。
- 分项得分。
- 推荐理由。
- 风险点。
- 证据来源。
- 建议面试问题。
- 简历预览。

主要按钮：

- 复制推荐理由。
- 复制面试问题。
- 导出推荐包。
- 返回列表。

状态：

- 证据充分。
- 存在低置信度风险。

## 13. HR 导出包页

页面目标：

- 让 HR 将结果带回现有工作流。

主要模块：

- 导出格式选择。
- 候选人选择。
- 字段预览。
- 输出预览。

导出格式：

- Excel / CSV。
- 邮件正文。
- 飞书 / 企业微信 / 钉钉摘要。
- 面试评价表。
- JSON。

主要按钮：

- 下载。
- 复制。
- 返回推荐列表。

## 14. 内部调试页

页面目标：

- 方便检查 Agent 输出质量。

主要模块：

- Agent 运行列表。
- Prompt 版本。
- 输入 JSON。
- 输出 JSON。
- warnings。
- 置信度。
- 运行耗时。

主要按钮：

- 查看详情。
- 复制 JSON。
- 标记问题。
